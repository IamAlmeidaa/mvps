# Sync Market

O Sync Market é um serviço independente de inteligência de mercado para lojas de hardware e componentes de PC. A proposta é ajudar lojistas a acompanhar preços e movimentos da concorrência com mais contexto, reagindo mais rápido para proteger margens e oportunidades de venda.

O site apresenta a proposta do serviço, conceitos em desenvolvimento e um formulário para lojistas interessados entrarem em contato. Os exemplos visuais são conceituais e não representam resultados de clientes.
